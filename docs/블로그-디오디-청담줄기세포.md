## 큐레이션 근거 — 기존 글과 어떻게 가르는가

⚠ **이 주제는 기존 `dod-cheongdam-skin`과 겹칠 위험이 가장 컸다.** 그 글은 "청담에서 피부과 고르는 5가지 기준"이 축이지만, 곁가지로 호밍 효과·안티에이징 구분·줄기세포/NK세포 비교표·성체 vs 주산기·기관 인증까지 이미 다뤘다.

원문 5편을 대조해 **기존 편에 없는 것만** 남겼더니 하나의 축이 나왔다 — *어떤 세포를, 어떤 순서로, 무엇을 지키면서*.

| | `dod-cheongdam-skin` (기존) | `dod-cheongdam-stemcell` (신규) |
|---|---|---|
| 축 | 병원을 **고르는** 기준 | 세포를 **고르는** 기준과 시술 전후 관리 |
| NK세포 | 비교표 한 줄 ("면역") | 면역 균형의 중심이라는 작동 원리, 대상군, 채취·배양 |
| 순서 | 없음 | **지병 유무가 시작점을 정한다** — 신규 핵심 |
| 세포 출처 | 성체 vs 주산기 | 지방 유래 vs 말초혈액 유래 (다른 분류축) |
| 시술 전후 | 컨디션 일반론 | 3일 금주, 약물 금기, 생착 1주, 멍·붓기 경과 |

**의도적으로 다시 쓰지 않은 것**
- 호밍 효과의 원리 설명 (기존 §"줄기세포는 기존 리프팅·스킨부스터와 무엇이 다른가요?")
- 안티에이징 = 억제 / 줄기세포 = 되돌림 구분 (기존이 이미 프레임까지 세움)
- 성체 vs 주산기 줄기세포, 세포 크기와 정착률
- 기관 인증 vs 연구·특허 기록의 차이
- 첨단재생의료실시기관 지정의 의미 → 매거진 `guide-advanced-regenerative-medicine-clinic`이 전담

**신규성이 확실한 것**
- NK세포가 **면역을 눌러주기도 하고 끌어올리기도 하는** 균형의 중심이라는 설명
- 항암 치료 후 재발 우려·만성질환군이 NK를 먼저 찾는 이유
- **지병이 없으면 줄기세포부터 / 있으면 NK로 토대를 먼저** — 이 글의 뼈대
- 혈액 70cc → 2주 배양 → 2주 간격, 얼굴 3cc vs 정맥 240cc, 지방 50~100cc
- 증폭 수치(1천만~5천만 → 1억·5억·10억), 정맥 주입 시 체중 1kg당 100만 개
- 휴면 상태의 세포를 깨우는 활성화 과정
- 염증이 많으면 좋은 세포가 나오지 않는다 → 3일 금주
- **타이레놀은 되고 진통소염제·스테로이드는 안 되는 이유** (면역세포의 조직 이동을 막는다)
- 생착 1주, 멍 1주·붓기 3~5일
