## 큐레이션 근거

**왜 이 주제인가** — 기존 디오디 6편의 H2를 전부 뽑아 보면 **당기는 것**(리프팅의 층·주기), **톤**(색소·모공·장벽), **재생**(줄기세포 3편)으로 나뉜다. **채우는 것(볼륨)이 0편**이었다. 2026-10에 올라온 신규 원문 3편이 전부 이 영역이라 재고도 충분했다.

**축** — **무엇을 채우고 무엇을 자라게 하나.** 꺼짐의 원인 → 부피를 채우는 방식과 콜라겐을 자극하는 방식의 차이 → 제형(액상/입자) → 부위 → 디자인을 넓게 나누는 이유 → 변화 시점 → 회차와 간격 → 콜라겐 직접 보충 계열 → 주입 도구 → 붓기와 멍 → 일정 역산 → 시술 후 생활 → 병행 → 상담 체크리스트.

**기존 편과의 이음새** — `dod-cheongdam-lifting`은 **어느 층을 당기나**, `dod-cheongdam-cycle`은 **언제 다시 받나**, 이 글은 **무엇을 어느 자리에 채우나**. 리프팅 후 볼 꺼짐은 이미 `dod-cheongdam-skin`과 `dod-cheongdam-cycle`에 있어 이 글에서는 다루지 않고 링크로 넘겼다.

**같은 라운드의 힐하우스 편과의 구분** — 이번 라운드 힐하우스 건대점 편도 "주입"을 다룬다. 디오디는 **무엇을 어느 자리에 채우나**(부위 설계·시점·제형), 힐하우스는 **어떤 도구로 어느 깊이에 넣나**(주입 기법·회복)로 축을 갈랐다. 겹치는 지점은 끝이 둥근 관 한 문단뿐이고, 디오디 쪽은 혈관 손상과 멍, 힐하우스 쪽은 엠보와 분산 주입으로 서술 방향이 다르다.
