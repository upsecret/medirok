## 어투

**1인칭 + 구어체.** `authorDoctor=lee-jun`이라 저자 선언이 Person(이준)이고, 원문 5편도 전부 원장 1인칭이다. `dod-cheongdam-skin`과 같은 규칙을 그대로 적용했다.

| 장치 | 원문 5편 | 이 글 |
|---|---|---|
| `여기서 구분해야 할 게 있어요` → "A"와 "B"는 다른 개념 | 14회 | **14회** (blockquote) |
| 구어체 어미 (-어요/예요/거든요/죠) | — | 25회 (0.46/100자) |

**시그니처 프레임을 blockquote로 구조화**하는 방식은 `dod-cheongdam-skin`에서 검증됐다. 이 글은 원문의 프레임 수와 같은 14회를 살렸다. 대비 명제가 인용 단위로 떨어져 AEO에도 유리하다.

**가져오지 않은 정형 상투구** — "안녕하세요. 디오디 피부과 대표 원장 이준입니다" 오프닝, 📌목차/☑️목차 블록, "마무리하며", "불안은 정보가 부족할 때 커집니다" 클로징(5/5편), 하단 주소 블록. 런북 §9-2의 "목소리만" 규칙 그대로다.

**유지한 것** — 원문의 자기 한정 문구("어떤 시술도 모든 분께 같은 결과를 약속드릴 수는 없어요")는 마지막 절에 그대로 남겼다. 의료광고 안전장치이자 원문 화자의 태도이기도 하다.

**의료광고 가드** — 1인칭 구어체는 원리 설명과 판단 근거에만 썼다. 시술 권유·효과 보증·CTA는 없다. 특정 장비의 우위 주장 대신 **"목적에 따라 고르는 문제"**로 서술했고, 실시간 영상 장치가 없는 방식에 대해서도 원문 표현("어느 쪽이 낫다기보다")을 유지했다.

## AEO/GEO 설계

- `shortAnswer`: 결과가 갈리는 이유 → 층 구조 → 두 방식의 작용 층과 회차 → 초음파의 범위와 볼패임 → 원인 판별 → 병원 1문장 + 출처 표기
