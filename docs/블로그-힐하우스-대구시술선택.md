## 큐레이션 근거

**왜 이 주제인가** — 특정 시술이 아니라 **고르는 법**이라 브랜드 의존이 낮고, AEO에서 자주 묻는 "피부과 어떻게 고르나"에 답한다. 대구점 원장 3명의 칼럼이 같은 축으로 모인다.

**축** — **나이표가 아니라 지금의 피부 상태로, 시술 목록이 아니라 진단으로 고른다.** 피부 평가 → 개인차 → 상담 체크리스트 → 과잉 권유·당일 결제 → 비교 상담 → 효과 확인 → 기대치 → 사후 관리.

**기존 메디록 글과의 관계** — `dod-cheongdam-skin`(디오디)이 정품 팁 확인·샷 수 설계를 다뤘다. 그래서 같은 내용이 중심인 `lifting-device-selection`(박효진)은 제외했고, `choosing-clinic-doctor`의 정품 확인 문단도 옮기지 않았다.

**의료법 인용** — 원문(김현욱 원장)이 든 의료법 제27조 제3항(영리 목적 환자 유인 금지)은 "원문에 따르면"으로 출처를 밝혀 옮겼다.

## 작성 시 지킨 규칙

- **원출처가 병원 웹사이트다** — 네이버가 아니다. 화면 문구("의원 공식 웹사이트 기반 재구성", "(웹사이트)")와 JSON-LD `citation[].@type`(Article)은 `src/lib/blog-source.ts`가 URL 호스트로 판정한다.
- **병원 명의** — `authorDoctor` 없음 → JSON-LD `author`는 해당 지점(Organization). 원장의 판단은 인용 블록으로 옮기고 "— ○○○ 원장 · 힐하우스피부과 칼럼"으로 밝혔다. 인용 블록 안 문장은 원문 문장 그대로다.
- **지점 귀속** — 블로그 글은 지점 1곳에 붙는다. 저자 소속이 틀어지지 않도록 **그 지점 원장의 칼럼끼리만** 묶었다.
- **사실은 시드 검증분** — 주소·역·진료시간·전문의 수는 `scripts/seed-healhouse.ts`(지점 페이지 JSON-LD) 기준.
- **원문 수치는 출처를 밝혀 옮겼다** — "원문이 인용한 연구에 따르면" 형태. 최상급·타 기관 대비 우위 주장은 옮기지 않았다.
- **CTA·자기 홍보 문장 제거** — 원문의 "힐하우스는 ~을 원칙으로 합니다" 류는 옮기지 않았다.
