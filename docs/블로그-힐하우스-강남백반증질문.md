## 큐레이션 근거

**왜 이 주제인가** — 기존 `healhouse-gangnam-vitiligo`는 **치료법**(활동성/안정기 구분, 광선치료, 연고, 기간)을 다뤘다. 배정민 원장의 백반증 칼럼 28편 중 5편만 쓴 상태였고, 남은 23편에는 **환자와 보호자가 실제로 묻는 것**이 따로 모여 있다. 원문 자체가 "커뮤니티 게시글 1,000건에서 예후 질문이 42%"라고 말하는 영역이다.

**축** — 치료법이 아니라 **질문**. 왜 생기나 → 왜 얼굴이 잘 회복되나 → 전염되나 → 무엇이 악화시키나 → 유전되나 → 가족력이 있으면 → 부모가 더 걱정하는 이유 → 수명 → 임신 → 광선치료 장기 안전성 → 레이저 시술 → 시술 전후 확인.

**기존 메디록 글과의 관계** — 치료법 편과 **한 H2도 겹치지 않는다.** 두 편을 교차 링크해 "치료를 고를 때"와 "안고 살아갈 때"를 나눠 읽게 했다.
