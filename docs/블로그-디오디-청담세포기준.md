## 큐레이션 근거

**왜 이 주제인가** — 기존 4편 중 `dod-cheongdam-skin`이 "기관 인증 vs 연구 기록"을, `dod-cheongdam-stemcell`이 "NK세포와 줄기세포의 기능 차이"를 다뤘다. **배양의 허용 범위와 세포의 출처(성체/주산기/자가)** 축은 비어 있었고, 원문 자산이 가장 두껍게 쌓인 구간이기도 하다.

**축** — **"어떤 세포인가"보다 "어떻게 얻고 어떻게 다루는가"**. 추출 즉시 사용 vs 배양 → 세포 수 → 배양 관리 난이도 → 제도 → 기관 요건 → 세포 분류 → 자가 세포의 한계 → 주산기 세포 → 세포 크기와 전신 분포 → 선별 기준 → 상담 체크리스트.

**기존 메디록 글과의 관계** — 매거진 `guide-advanced-regenerative-medicine-clinic`(첨단재생의료실시기관)과 키워드가 겹친다. 런북 §9-2에 따라 역할을 나눴다 — **매거진은 기관 제도와 고르는 기준, 이 블로그는 원장 관점의 절차·세포 서술**. 본문에서 매거진으로 교차 링크한다.

## 사실 처리

- **"국내 피부과 최초 보건복지부 지정 첨단재생의료실시기관"**은 `seed-dod.ts`의 검증된 시드 값이다(`certification.stage1Detail`). 원문이 아니라 시드에서 가져왔다.
- 원문 [참고 및 출처]의 PMC 논문 3건은 **"원문이 인용한 연구에서는 …으로 보고됐습니다"**로 귀속해 옮겼다. 메디록이 직접 인용한 것처럼 쓰지 않았다.
- 세포 지름은 원문의 `20~30μm`를 한글 단위(마이크로미터)로 풀어 적었다.
