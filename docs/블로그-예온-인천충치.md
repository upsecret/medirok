## 큐레이션 근거 — 기존 글과 어떻게 가르는가

충치는 예온 블로그에서 가장 큰 미소진 클러스터다(7편). 다만 `yeon-incheon-dental`(1-1)이 §7~8에서 충치를 이미 다뤘으므로 축을 옮겼다.

| | `yeon-incheon-dental` (기존) | `yeon-incheon-cavity` (신규) |
|---|---|---|
| 질문 | **무엇으로 때우는가** — 재료와 술식 | **치료할지 말지를 무엇으로 판단하는가** |
| 분류축 | 법랑질/상아질/신경/치수 **4단계 진행표** | 인접면 우식 **E1·E2·D1·D2·D3** (다른 분류) |
| 범위 | 충치는 전체의 일부(임플란트·보철과 함께) | 충치 하나만 |
| 치료 후 | 다루지 않음 | 시림, 반복의 원인, 비용이 갈리는 이유 |

**의도적으로 다시 쓰지 않은 것** (1-1이 맡고 있음)
- 1~4단계 진행표(법랑질 → 상아질 → 신경 염증 → 치수 손상)
- 레진 / 골드·세라믹 인레이 / 크라운 **재료 구분**
- 신경치료가 필요한 3가지 경우, 골드 크라운의 특성
- 치아 상실 자리를 방치했을 때의 변화

**신규성이 확실한 것**
- **치과마다 판단이 갈리는 이유** — 충치의 *활동성*을 보고, 그 판단이 임상 경험과 주관적 해석에 기댄다는 점
- 초기 비와동성 우식 / 정지 우식 — **드릴 없이 재광화로 관리**하는 접근
- 진행 속도의 개인차 — 나이·식이·양치 습관, 그리고 **침의 점도와 양**
- 인접면 우식의 **E1/E2/D1/D2·D3** 분류와 단계별 치료 필요성
- **엑스레이의 한계** — 열어 보면 영상보다 깊고 넓은 경우가 많다
- 치료 후 시림의 지속 기간과 **재검사 기준**
- 같은 부위 반복 충치는 습관 문제라는 것, 인접면은 자각이 어렵다는 것
- **비용이 갈리는 이유** — 범위·깊이, 치아 위치(앞니 vs 어금니, 인접면), 재료 품질과 술식
- 산성 음식 후에는 **바로 닦으면 안 된다**(침식 vs 충치)
