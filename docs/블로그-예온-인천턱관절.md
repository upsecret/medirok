## 큐레이션 근거

**왜 이 주제인가** — 기존 6편이 임플란트(2회)·라미네이트·교정·충치·치주를 덮었다. **구강악안면외과 영역은 완전히 비어 있었고**, 예온은 이 과의 전문의 진료 체계를 갖추고 있어 서술 범위가 닿는다. "턱에서 소리", "입이 안 벌어질 때", "이악물기"는 검색 의도도 분명하다.

**축** — 턱에서 나는 소리와 통증을 "그냥 피곤해서"로 넘기지 않게 하는 글. 증상 신호 → 자가 확인 → 관절 구조 → 원인(습관·스트레스·교합) → 방치했을 때의 확산 → 이악물기가 치아에 남기는 변화 → 보철물·임플란트 → 일상 관리 → 사랑니·발치와의 연결 → 발치 후 관리.

**기존 메디록 글과의 관계** — `yeon-incheon-cavity`가 시린 증상을, `yeon-incheon-ortho`가 교합을 다뤘다. 이 글은 **시림을 이악물기의 결과로**, **교합을 턱관절 부담의 원인으로** 각각 다른 방향에서 잡아 겹치지 않게 했다. 두 편에 교차 링크한다.
