## 사실 검증 — 발행팩 `[확인]` 항목 처리

발행팩 원고 01의 `[확인: 진료시간·전문의 구성 최신 여부]`는 `scripts/seed-yeon.ts`로 전부 뒷받침되므로 **태그만 제거하고 오히려 구체화**했다.

| 서술 | 근거 (seed-yeon.ts) |
|---|---|
| 약 900평 병원급 | `certification.stage1Detail`, `curationNote` |
| 원내 Ye-On Dental Lab | `stage1Detail`, `tags: 자체 기공소` |
| 보건복지부 인증 전문의(교정·구강악안면외과·소아치과·보철·통합치의학) | `stage3Detail` + `doctors[]` 개별 credentials |
| 아라역 6번 출구 도보 1분 | `nearestStation`, `walkingMinutes: 1` |
| 화·목 20:30 / 토·일 17:00 (점심 13:00–14:30) | `hours` |
| 라미네이트 진료 | `tags: 라미네이트` |

가격은 `prices: []`(공식 확인 전)이므로 **priceTable 미사용** — 추정가 미조작 원칙.
