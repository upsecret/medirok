## 큐레이션 근거 — 기존 글과 어떻게 가르는가

예온 블로그에서 임플란트는 교정 다음으로 큰 클러스터이고, 최근 6개월 게시물에 네비게이션 방식이 반복해서 나온다. 그런데 기존 `yeon-incheon-dental`이 이미 네비게이션 임플란트를 다뤘다. **그대로 또 쓰면 중복 색인이 된다.**

그래서 축을 옮겼다.

| | `yeon-incheon-dental` (기존) | `yeon-incheon-implant` (신규) |
|---|---|---|
| 성격 | 넓고 얕음 — 임플란트 + 충치 + 보철을 한 편에 | 임플란트 하나만 |
| 네비게이션 | **무엇인가** (정의·비교표·시뮬레이션 정밀도) | **누구에게 맞고, 무엇을 준비하는가** |
| 케이스 | 전악 임플란트 1건 서사 | 케이스 없음 — 판단 기준과 준비 절차 |
| 회복 | 다루지 않음 | 회복이 갈리는 3요소, 기저질환별 차이 |

**의도적으로 다시 쓰지 않은 것** (기존 편이 이미 맡고 있음)
- 네비게이션 vs 기존 방식 비교표 → 정의는 한 문장으로만 두고 크로스링크
- 당일 임시치아·통증 감소·당뇨 환자 혈당 관리 서사
- 치아 상실 방치 시 인접치 기울어짐 (기존 §"치아를 잃은 자리를 방치하면")
- 충치·신경치료·크라운 전반

**신규성이 확실한 것** (기존 5편 어디에도 없음)
- 네비게이션이 실제로 **두 가지 방식**을 뭉뚱그린 용어라는 점 (사전 설계형 / 수술 중 실시간 추적형)
- 가이드 제작에 **며칠~일주일**이 걸려 당일 수술이 안 된다는 점
- CT 촬영 자체의 제약 (임신 중·특정 질환)
- 적용이 유리한 3가지 조건 (뼈 얇음·신경관 근접·다수 동시 식립)
- 골유착 2~3개월 / 전체 3~6개월
- 회복이 갈리는 3요소 중 **셋째만 환자가 고를 수 있다**는 프레임
- 수술 후 주의사항을 문서로 받아야 하는 이유
