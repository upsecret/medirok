## 사실 검증 — 발행팩 원고에서 **삭제·교체한 서술**

이 글이 4편 중 수정이 가장 많다. 발행팩 원고의 "구별 특징"이 출처 없는 밀집도·비율 주장이었기 때문.

| 원문 | 처리 |
|---|---|
| "남동구(구월동) — 인천터미널 상권 중심으로 **교정 전문 의원이 밀집**" | 밀집 주장 삭제 → "인천터미널 상권을 중심으로 한 생활권" |
| "연수구(송도) — 국제도시 특성상 **디지털 장비 도입 의원이 다수**" | 삭제 → "국제도시 생활권, 인천 1호선 축" |
| "부평구·계양구 — 역세권 중심, **야간·주말 진료 운영 비율이 높음**" | 비율 주장 삭제 → "1호선·7호선 역세권 중심 생활권" |
| "서구(검단·청라) — **신도시 개발로 신규 개원이 많고 시설이 비교적 최신**" | 삭제 → "인천 2호선과 공항철도 생활권. 검단신도시에는 병원급 치과가 있어…" |
| FAQ "검단 쪽 치과는 어떤가요?" 답변의 "신규 개원이 많아 시설이 최신인 편" | 동일하게 삭제 |
| `[확인: 규모·장비 최신 여부]` | 태그 제거, 본문 유지 (seed-yeon.ts 근거) |

대신 **"구별로 어떤 의원이 있는지는 지역마다 다르므로 건강보험심사평가원 병원 조회로 확인"** 안내를 넣어 독자가 직접 검증하도록 했다. 근거 없는 지역 서열화 대신 검증 경로를 제시하는 편이 E-E-A-T에도 유리하다.

예온 문단 근거는 `docs/매거진-인천라미네이트-가이드.md`의 검증 표와 동일.
