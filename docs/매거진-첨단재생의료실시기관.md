### ⚠ type / category 설계 판단

발행팩은 카테고리를 `醫錄 인증`으로 지정했다. 그런데 `type`은 DB enum(`article|qna|regional|interview|case`)이고 **새 값을 추가하려면 Payload 마이그레이션이 필요**하다. `category`는 자유 텍스트 필드(`Magazines.ts`)이므로:

- `type: "article"` + `category: "醫錄 인증"` 조합으로 처리
- 카테고리 목록 페이지는 `type` 기준 라우팅이라 이 글은 `/magazine/category/article`에 노출된다 (`/magazine/category/醫錄 인증`는 존재하지 않음)
- `MagazineCard`는 타입 배지("시술 가이드")와 `category` 텍스트("醫錄 인증")를 함께 렌더한다. 레거시 글 `gangnam-implant-price-guide-2026`이 `type: article` + `category: 가격 가이드`로 이미 같은 패턴을 쓰고 있다
